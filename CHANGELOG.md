# История изменений

Здесь перечислены изменения собранных в проекте версий. Даты публикации не указаны: GitHub-релизы ещё нужно оформить владельцу.

## 1.3

### Добавлено

- Название и исполнитель в настройках трека с автоматическим запуском поиска текста.
- Встроенное окно результатов LRCLIB и автоматическое сохранение точного совпадения.
- Ручной выбор неоднозначного результата и вставка своего текста или LRC.
- Кнопка «Субтитры», подсветка строк по LRC-меткам, следование и сдвиг времени.
- Офлайн-кэш с проверкой соответствия названию и исполнителю.
- Градиент карточки по двум оттенкам обложки, интенсивность, направление и предпросмотр.
- Поля метаданных с совместимым чтением старых записей библиотеки.

### Изменено

- Поиск текста выполняется внутри приложения вместо перехода во внешний браузер.
- Добавлено разрешение `INTERNET` для поиска новых текстов; HTTP без шифрования запрещён.
- Просмотр текста другого трека не переключает текущую музыку.

## 1.2.1

- Центрирование элементов карточки и заголовок `volna`.
- Размер карточки рассчитывается по содержимому, без растягивания фоновой подложкой.
- Более короткая перемотка и безопасные отступы у ползунков во всех настройках.
- Кнопка поиска текста через внешний браузер — впоследствии заменена встроенным поиском в 1.3.

## 1.2

- Четвёртая вкладка «Настройки», отдельные разделы звука, оформления и приложения.
- Темы, RGB/HEX, собственные фоны, области применения и адаптация по обложке.
- Эквалайзер, скорость, тон, баланс и дополнительные параметры приложения.
- Плавные переходы и обновлённая карточка прослушивания.

## 1.0.1

- Исправлен вылет при создании главного экрана: вместо обращения к элементу таймера по индексу используется прямая ссылка.

## 1.0

- Первый Android APK: локальная библиотека, импорт нескольких файлов и переименование.
- Плеер, фоновые элементы управления, случайный трек, повтор и таймер.
- Режимы стерео и моно для одного уха.
