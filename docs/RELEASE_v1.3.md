# Volna 1.3 — тексты песен, субтитры и градиенты

Тестовый Android-релиз с поиском текстов внутри приложения и новым оформлением карточки плеера.

## Главное

- **Название и исполнитель.** Укажите их в меню трека и запустите автоматический поиск.
- **Тексты LRCLIB внутри приложения.** Точное совпадение сохраняется сразу, неоднозначный результат можно выбрать вручную.
- **Окно «Субтитры».** Подсветка LRC-строк, следование за песней, сдвиг времени и офлайн-чтение сохранённого текста.
- **Градиент по обложке.** Два оттенка, интенсивность и направление только для карточки проигрывания.

## Как попробовать

Библиотека → ⋮ → «Название, исполнитель и автопоиск текста» → «Сохранить и найти». Затем откройте «Субтитры» на экране прослушивания.

Градиент: Настройки → Оформление → «Градиент карточки по обложке».

## Установка

Скачайте **volna-1.3.apk** из Assets этого релиза. Требуется Android 8.0 или новее.

Обновление сохраняет локальные данные только при совместимом пакете и подписи. Если публичная сборка подписана другим ключом, она не установится поверх прежней тестовой. Не удаляйте предыдущую установку, если ещё не сохранили нужные данные отдельно.

## Что важно знать

Музыка и сохранённые тексты работают без интернета. Новые тексты загружаются из LRCLIB; не каждая песня есть в базе. Синхронизация работает при наличии временных меток, обычный текст отображается без них. Аудиофайл в сервис текстов не отправляется.

Сценарии проверялись в эмуляторе Android 15 с контролируемым ответом источника. Реальная работа кодеков, аудиоэффектов и энергосбережения зависит от телефона.
