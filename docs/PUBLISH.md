# Публикация на GitHub

Это оформление для Android-проекта Volna 1.3. Исходники и APK в комплект не входят.

## Добавление файлов

1. Распакуйте архив и добавьте его содержимое в корень исходников, где находятся `app/` и `build-apk.sh`.
2. В `README.md` замените `YOUR_USERNAME` на свой GitHub-логин, а `YOUR_REPOSITORY` — на название репозитория.
3. Сохраните выбранную на GitHub лицензию `LICENSE`. Комплект не меняет её и не назначает новую.
4. Не загружайте папку `signing/` из прежнего архива: в ней находится тестовый ключ. Правила исключения уже включены в `.gitignore`. Эти правила не удаляют ранее опубликованные файлы из истории Git.
5. Добавляйте файлы оформления с сохранением структуры `docs/assets/`, чтобы баннер отображался в README. При загрузке через сайт GitHub сначала распакуйте ZIP — GitHub не распаковывает загруженный архив в дерево репозитория.

## Релиз

- Тег: `v1.3`.
- Название: `Volna 1.3 — тексты песен, субтитры и градиенты`.
- Описание: содержимое `docs/RELEASE_v1.3.md`.
- Приложенный файл: `volna-1.3.apk`.

Для тестовой сборки отметьте pre-release. APK размещайте в Assets релиза, а не в исходниках. Ссылка загрузки в README заработает после публикации соответствующего релиза.

## Подпись APK

Для публичных обновлений нужен постоянный ключ подписи, который хранится вне репозитория. Если публичная сборка использует другой ключ, она не установится поверх прежней тестовой версии. Удаление приложения удаляет локальные данные.

В `LyricsRepository.java` также обновите ссылку на проект в строке `User-Agent` на адрес своего GitHub-репозитория.
